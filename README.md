# Porsche Sales Intelligence

Dashboard interativo para análise de vendas de veículos Porsche.

🔗 **Veja o projeto online:** https://karolinaelizabete.github.io/dashboard-porsche-sales/

## Sobre o projeto

Painel que transforma os dados de uma planilha de vendas em indicadores
e gráficos, para facilitar a tomada de decisão.

## Funcionalidades

- Filtros por modelo, ano-modelo, cidade, forma de pagamento e período;
- Indicadores: receita total, ticket médio, modelo, ano e cidade líderes;
- Ranking dos modelos mais vendidos;
- Receita por cidade e vendas por estado;
- Mix de formas de pagamento;
- Matriz de popularidade cidade × modelo;
- Insights automáticos com base nos filtros.

## Ferramentas

- HTML
- Excel (base de dados)
- ChatGPT (apoio no desenvolvimento)
- GitHub Pages

## Objetivo

Projeto desenvolvido como parte de um curso de Excel e IA, com foco em
análise e visualização de dados.
